# Setup and Preparation

This guide describes the preparation and documentation process for researching Yandex Alice smart speakers.

## 1. Before You Begin

Prepare the following information:

- Exact speaker model
- Hardware revision, if available
- Firmware version or build number
- Router model and network configuration
- Smartphone operating system and version
- Date of testing

## 2. Record Device Information

Before changing any settings, document the current state of the device.

1. Photograph the device and its model label, if accessible.
2. Record the firmware version shown by the official application, if available.
3. Confirm that the speaker works normally.
4. Record any existing connection or activation issues.

Do not publish account credentials, serial numbers, private IP details, or other sensitive information in public reports.

## 3. Network Preparation

Before conducting network-related tests:

- Confirm that you administer the network.
- Record the original DNS settings.
- Ensure that you can restore the original configuration.
- Avoid changing network settings for unrelated devices.
- Use only network endpoints whose purpose and ownership you understand.

## 4. Test Procedure

For every test, record:

- Device model and firmware
- Preconditions
- Steps performed
- Expected result
- Actual result
- Error messages, if any
- Recovery steps

## 5. Recovery and Troubleshooting

If the device stops working as expected:

1. Stop further modifications.
2. Restore documented network settings.
3. Restart the device using the manufacturer's normal procedure.
4. Consult official support documentation if the issue persists.
5. Record the failure without claiming an unverified fix.

## 6. Results

Only mark a procedure as verified after reproducing it on the specified device and firmware version.
