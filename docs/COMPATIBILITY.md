# Device Compatibility

This document tracks the compatibility research for Yandex Alice smart speakers.

## Compatibility Status

| Device Model | Status |
|---|---|
| Alice Lite | Reported working; verification pending |
| Alice Mini 1 | Reported working; verification pending |
| Alice Mini 2 | Reported working; verification pending |
| Alice Mini 3 | Firmware-dependent; further testing required |
| Alice Midi | Reported working; verification pending |
| Alice Station 2 | Reported working; verification pending |
| Alice Street | Exact model revision needs confirmation |
| Alice Smart Hub | Further verification required |
| Alice Lite 2 | Firmware-dependent; further testing required |
| Alice Station Max | Documented method reported incompatible |
| Alice Station 1st Generation | Documented method reported incompatible |

## Testing Requirements

For each test, record:

- Exact device model and revision
- Firmware version or build
- Test date
- Procedure performed
- Observed result
- Recovery procedure, if applicable

## Important Notes

Compatibility may vary between firmware versions and hardware revisions. Reported results should not be treated as independently verified until the procedure has been reproduced and documented.
